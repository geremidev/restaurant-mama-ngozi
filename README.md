# Chez Mama Ngozi : site vitrine

Site vitrine d'un restaurant de cuisine camerounaise (projet fictif réalisé pour mon portfolio).

## Fonctionnalités
- Mise en page responsive (mobile d'abord)
- Menu mobile accessible
- Animations au scroll (IntersectionObserver)
- Formulaire de réservation qui envoie un message WhatsApp prérempli

## Technologies
HTML5, CSS3 (variables, grid, flexbox), JavaScript vanilla
